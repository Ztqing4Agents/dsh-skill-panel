# v0.1.0

## 新增

- **技能面板基础视图**：在 DSH 侧栏新增「技能」入口，按「内置技能 / 本地技能 / 已安装技能」分组展示技能并提供每行独立启停开关。
- **字节保真写入**：切换开关时仅精确修改 `SKILL.md` 的 `disable-model-invocation` 字段，完整保留原有换行符（CRLF/LF）、BOM 与行序。
- **软链只读保护与边界提示**：软链技能标记为「软链·只读」并禁用写操作，页脚统计并提示项目级或未扫描目录中的技能数量。
