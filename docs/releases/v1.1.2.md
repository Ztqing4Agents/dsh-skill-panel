# v1.1.2

## 破坏性变更

- **宿主兼容范围收敛至 DSH `0.2.2` 系列**：`engines.dsh` 与宿主 `peerDependencies` 统一调整为 `>=0.2.2-0 <0.3.0-0`，不再支持 `0.2.0` / `0.2.1`（旧宿主用户请停留在 **`1.1.1`**）。

## 改进

- **内置插件默认图标对齐宿主**：缺少图标或加载失败时，列表区块与详情页头统一展示宿主默认插件图标（框内 `36×36`）。

## 修复

- **npm 预发布宿主依赖解析报错**：修复 npm 消费者工程在 `0.2.2-rc.x` 预发布宿主下安装报 `ERESOLVE` 的问题。
