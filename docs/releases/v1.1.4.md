# v1.1.4

## 破坏性变更

- **宿主支持面升级至 DSH `0.2.3` 系列**：宿主区间调整为 `>=0.2.3-0 <0.3.0-0`（`@deepseek-ai/cordis` 同步抬至 `>=4.2.0-0`），不再支持 DSH `0.2.2` 系列（旧宿主用户请安装 **`1.1.3`**）。

## 改进

- **适配 DSH `0.2.3` 路由访问策略**：插件全部十六条接口显式声明匿名访问，保持本机回环围栏与来源校验边界不变。
