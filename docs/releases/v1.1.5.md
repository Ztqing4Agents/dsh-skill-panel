# v1.1.5

> 类型：规范
> 读者：升级到本版本的人——判断自己会不会受影响、要做什么
> 真源：`CHANGELOG.md` 的 [1.1.5] 节 + git tag `v1.1.5`
> 更新触发：本版本发布后即冻结；只在发现事实性错误时追加「勘误」，不改已发布内容
> 规模上限：400

## 定位

市场页从「看一眼、再回已安装页动手」变成可以在原地更新已装技能，刷新失败也不再抹掉已经读到的结果；英文界面下的分类名与数量写法一并跟随界面语言。数据目录、安装台账与技能开关都不变。

## 亮点

- 已装技能有了自己的动作：市场卡片的动作位按实际状态显示「安装 / 更新 / 已是最新版本 / 已安装」，更新前的确认框写明从哪个版本到哪个版本、装到哪个目录，以及目录会被上游文件整体替换。
- 更新失败不再只剩一个按不动的「已安装」：已回滚、目录已丢失、结果无法确认三种情况各有各的说明；后两种还会补读一次已安装列表，把能读到的记录再读一遍。
- 刷新失败时保留上一次的结果：同一筛选下重试失败只多一条「刷新失败，请重试」，卡片不再整片消失。
- 英文界面的分类名与数量后缀随界面语言切换：分类显示 `Office Efficiency` 这类英文名，下载数写 `14K`（中文仍是 `1.4万`）。
- 详情页概览优先显示作者另写的短稿，取不到时依次回落平台中文译本、作者原文；装进技能目录的始终是作者原文。

## 新装

```bash
dsh plugin --profile <your-profile-name> add @ztqing4agents/dsh-skill-panel
```

装完重启 DSH，侧栏出现「技能」入口；桌面端也可在「插件」页点「添加插件」填上面的包名。

## 升级与迁移

- 在 DSH `0.2.3` 及以上的宿主上无需额外动作：数据目录、安装台账、开关状态与市场筛选都不动，重启 DSH 即生效。
- 支持面与 `1.1.4` 相同（`>=0.2.3-0 <0.3.0-0`）。仍停在 `0.2.2` 系列的用户请继续使用 `1.1.3`。
- 市场页里显示「更新」的技能，更新会用上游文件整体替换技能目录，本地改动随之丢失；确认框里有同样一句提示，改过技能文件的人请先备份。

## 已知问题

- 市场页仍没有刷新入口，切走页签再回来也不重新取数：上游的变化要重启 DSH 才能看到，行内「重试」只重拉当前筛选的第一页。
- 浅色主题下错误态文字的对比度是 `4.498:1`，差 `0.002` 未达 AA：颜色取自宿主令牌，本面板没有自己的颜色定义，要调只能由宿主侧换令牌。
- 英文界面下的卡片描述仍是平台中文：描述与概览正文只有一段字符串，按界面语言挑字段要改数据形状，本轮未做。

## 验收

- `npm view @ztqing4agents/dsh-skill-panel@1.1.5 version` 输出 `1.1.5`。
- 已有台账的已装技能在市场页：动作位显示「更新」，确认框写明「从 → 到」与目标目录；更新成功后动作位变成不可点的「已安装」，台账版本与上游最新版本相同的技能则显示不可点的「已是最新版本」。
- 断网后在同一筛选点「重试」：列表保留原卡片，只多出一条「刷新失败，请重试」；换成没成功加载过的筛选，仍是整页错误态。
- 界面语言切到英文：分类显示 `Office Efficiency` 等英文名，下载数写 `14K`；切回中文恢复 `1.4万`。
- 详情页概览：有作者短稿的技能显示短稿，没有的显示中文译本，再没有的显示作者原文。

全量变更见 `CHANGELOG.md` 的 [1.1.5] 节。
