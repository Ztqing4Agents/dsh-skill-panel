# v1.1.5

## 新增

- **技能市场原地更新**：市场卡片支持直接更新已安装技能，更新前弹窗确认版本变更并保留原有启用状态，失败时按回滚或目录异常分级提示并自动校准列表。

## 改进

- **详情页概览优先展示作者短稿**：有作者短稿时优先展示，缺失时依次回落中文译本与作者原文；安装仍写入作者原文。
- **英文界面分类与数量单位本地化**：分类筛选随语言切换为英文名，下载与收藏数在英文界面显示为 `K` / `M`（中文保持「万」）。

## 修复

- **刷新失败清空已加载列表**：修复同一筛选下刷新失败导致已有卡片被清空的问题，改为保留列表并在顶部提示「刷新失败，请重试」。
- **市场骨架卡排版跳变**：修复首次加载时骨架卡标题占位宽度塌陷为 `0` 的问题。

## 注意事项

- 在市场页执行「更新」会用上游文件整体替换技能目录，本地手动修改会丢失，操作前请先备份。
