## 定位

协议换成 MIT、插件展示名本地化、图标按品牌色重绘——界面行为与本地数据都不变。

## 亮点

- 许可由 BSD-3-Clause 改为 **MIT**，自本版起生效（`LICENSE`、`package.json` 与文档徽标同轮更新）。
- 插件在 DSH「插件」页显示为「技能面板」/ `Skill Panel`，随宿主语言自动切换。
- 图标重绘：深墨蓝底、白线加琥珀高亮，右下角带宿主插件风车水印，铺满宿主 `36×36` 展示框并适配深色主题。

## 新装

```bash
dsh plugin --profile <your-profile-name> add @ztqing4agents/dsh-skill-panel
```

装完重启 DSH，侧栏出现「技能」入口；桌面端可在「插件」页点「添加插件」填上面的包名。

## 升级与迁移

- 无破坏性变更：直接升级并重启 DSH 即可，数据目录、安装台账与开关状态都不动。
- 许可变化只从本版起算：`1.1.0` 及更早仍适用 BSD-3-Clause，如果你要分发或再许可，按所装版本核对 `LICENSE`。
- 侧栏入口名（「技能」/ `Skills`）与插件名（「技能面板」/ `Skill Panel`）是两套文案，本版只改后者。

## 已知问题

- registry 上已发布版本的元数据不可改：`npm view @ztqing4agents/dsh-skill-panel@1.1.0 license` 仍显示旧协议，这是正常的。
- 图标文件随仓库与包发布，市场侧怎么显示图标取决于市场自己读哪个图片字段，不由本版决定。

## 验收

- `npm view @ztqing4agents/dsh-skill-panel@1.1.1 version` 输出 `1.1.1`。
- `npm view @ztqing4agents/dsh-skill-panel@1.1.1 license` 输出 `MIT`。
- 升级并重启 DSH 后，「插件」页该条目的名称随界面语言显示「技能面板」或 `Skill Panel`，侧栏入口仍是「技能」/ `Skills`。
- 插件条目与详情页头显示新图标，放大到 `36×36` 展示框时无留边、深色主题下底色不发灰。
