# v1.0.0

`dsh-skill-panel` 首次公开发布，在 DSH 侧栏提供「技能」管理面板并内置 SkillHub 技能市场。

## 破坏性变更

- **项目更名为 `dsh-skill-panel`**：原 `dsh-skill-center` 不可与新版同时启用，升级前请先卸载旧包；内部 API 前缀同步调整为 `/api/dsh-skill-panel/*`。
- **本地数据目录迁移**：存储目录由 `$DSH_HOME/dsh-skill-center/` 变更为 `$DSH_HOME/dsh-skill-panel/`，从 `0.1.0` 升级前请先迁移目录：

  ```bash
  mv ~/.dsh/dsh-skill-center ~/.dsh/dsh-skill-panel
  ```

## 新增

- **SkillHub 技能市场**：接入 `skillhub.cn` 镜像，支持三档来源切换、搜索、分类筛选、多维排序、内嵌详情与一键安装至 `~/.dsh/skills/<name>`。
- **本地与 GitHub 仓库导入**：「＋ 添加技能」支持导入本机目录与公开 GitHub 仓库（含子目录与多技能候选），采用浅克隆且不执行仓库脚本；下拉菜单提供「让 Agent 创建技能」入口。
- **详情查看与版本管理**：支持查看 `SKILL.md` 正文与磁盘路径、自动/手动检查更新、一键覆盖升级（失败自动回滚）与卸载。
- **无损启停与软链保护**：切换开关仅修改 `disable-model-invocation` 字段并保留原文件格式；软链技能只读保护。

## 改进

- **数据源统一与图标渐进加载**：市场数据与安装包统一走 `skillhub.cn` 同源镜像，已安装列表支持渐进加载上游图标。
- **滚动与交互优化**：切换筛选、搜索或关闭下拉菜单时保持稳定滚动落点，消除骨架屏闪烁。

## 修复

- **代码块渲染回退**：修复 `SKILL.md` 含代码块时整篇回退为纯文本的问题。
- **列表行高与图标偏差**：对齐宿主 `48×48` 图标与 `64px` 行高规范。
- **搜索框双清空按钮**：移除浏览器原生取消按钮与自定义清空按钮的重叠。

## 移除

- **图标代理路由**：下线 `market/lucide` 与 `market/clawhub-icon`，改用镜像图片直链。
- **市场卡片本地收藏开关**：仅展示上游收藏数，下线本地收藏按钮。

## 注意事项

- 本版最初以无作用域包名 `dsh-skill-panel` 发布，该包名现属第三方无关包，当前安装请使用 `@ztqing4agents/dsh-skill-panel`。
