# v1.0.0

> 类型：规范
> 读者：升级到本版本的人——判断自己会不会受影响、要做什么
> 真源：`CHANGELOG.md` 的 [1.0.0] 节 + git tag `v1.0.0`
> 更新触发：本版本发布后即冻结；只在发现事实性错误时追加「勘误」，不改已发布内容
> 规模上限：400

## 定位

技能面板的首次公开发布：在 DSH 侧栏提供一个「技能」入口，把内置、本地与市场安装的技能收进同一页，并首次带上接入 `skillhub.cn` 镜像的技能市场。

## 亮点

- 侧栏新增「技能」入口，内置 / 本地 / 已安装三档在同一页列完，每行一个独立开关。
- 内置技能市场：三档来源（所有来源 / SkillHub / ClawHub）、关键词搜索、分类筛选、四种排序与无限滚动，可一键装到 `~/.dsh/skills/<name>`。
- 「＋ 添加技能」支持本机目录与 GitHub 仓库（含子目录）；仓库里有多份 `SKILL.md` 时列候选供选，安装走浅克隆、不留 `.git`、不执行仓库脚本。
- 已安装技能可看 `SKILL.md` 渲染正文、调用名与磁盘路径，并支持自动与手动检查更新、覆盖升级（失败回滚）与卸载。
- 启停只改 `SKILL.md` 里的一个字段，换行符、BOM、注释与行序原样保留；软链技能标「软链 · 只读」且不提供开关。

## 新装

```bash
dsh plugin --profile <your-profile-name> add dsh-skill-panel
```

装完重启 DSH，侧栏出现「技能」入口。桌面端也可在「插件」页点「添加插件」填同一个包名（注意：本版用的是无作用域包名，见下节）。

## 升级与迁移

- **【不兼容】包名变更**：项目由 `dsh-skill-center` 更名为 `dsh-skill-panel`，内部 API 路由前缀同步改为 `/api/dsh-skill-panel/*`。旧包与新包**不能同时启用**，先卸载旧包再装新包。
- **【不兼容】本地数据目录迁移**：存储目录由 `$DSH_HOME/dsh-skill-center/` 改为 `$DSH_HOME/dsh-skill-panel/`，含安装台账、收藏与内置技能开关状态。从 `0.1.0` 升级前先搬目录，再在 Profile 里移除旧包、安装新版：

  ```bash
  mv ~/.dsh/dsh-skill-center ~/.dsh/dsh-skill-panel
  ```

- 市场数据与安装包统一走 `skillhub.cn` 同源镜像，卡片与详情不再出现两套数据；这一步不需要你做任何操作。

## 已知问题

- 市场卡片上的本地收藏开关本版下线，卡片只展示上游收藏数（底层存储与接口保留）。
- 更新是覆盖升级，本版没有版本回退入口；回退需要手动移除目录后重装。
- 本版在 npm 上用的是无作用域包名 `dsh-skill-panel`；该名字现在属于第三方无关包，**不要照抄上文的历史安装命令**，安装当前版本请照 `README.md` 的安装指南执行。

## 验收

- `git tag --list 'v1.0.0'` 有输出，且 `git show v1.0.0 --stat` 的首行是 `dsh-skill-panel 1.0.0（技能面板）——首次公开发布`。
- 照 `README.md` 的安装指南装一次当前版本并重启 DSH，侧栏出现「技能」入口。
- 打开面板后「已安装」页签按「内置技能 / 本地技能 / 已安装技能」三档分组列出技能，每行右侧有开关。
- 切到「技能市场」页签并切一次数据源（所有来源 / SkillHub / ClawHub），卡片能出图即说明镜像链路可用。
