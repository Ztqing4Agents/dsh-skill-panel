# v1.1.0

## 破坏性变更

- **迁移至 npm 作用域包 `@ztqing4agents/dsh-skill-panel`**：请先卸载旧包再安装新包并重启 DSH，**切勿同时启用**（否则触发 `webserver: duplicate exact route` 冲突）；无需移动 `$DSH_HOME/dsh-skill-panel/` 目录，原有数据自动沿用：

  ```bash
  dsh plugin --profile <your-profile-name> remove dsh-skill-panel
  dsh plugin --profile <your-profile-name> add @ztqing4agents/dsh-skill-panel
  ```

## 改进

- **前端装载标识同步**：对齐新作用域包名，避免启动时触发 `loaded without registering` 异常。

## 注意事项

- npm 上无作用域的同名包 `dsh-skill-panel` 为第三方无关包，安装时请确认包含 `@ztqing4agents/` 前缀。
