# v1.1.3

## 改进

- **市场描述优先展示平台中文**：卡片与概览兜底对齐上游站点，优先取平台中文描述，缺失时回落作者原文。
- **详情页概览优先展示官方中文译本**：有官方中文译本时优先展示译文，缺失时回落原文；本地安装仍写入作者原文。

## 修复

- **未认领技能署名显示账号 ID**：修复卡片与详情页将部分作者显示为 `user_` 内部账号标识的问题，改为展示作者名。
- **部分市场卡片缺失描述**：修复作者原文为空的技能（如 `ppt-generator-skill`）不显示描述行的问题。

## 注意事项

- 市场描述目前仅提供单语字段，英文界面下仍显示该段平台中文描述。
